# Processed Trading Instructions Archive

This directory stores historical or already-processed Trading instruction files.

These files remain available as documentation, but they are not the primary operational source of truth for new implementation work.

## Structure

- `phases/`: completed phase and sprint implementation notes.
- `legacy/`: superseded plans, duplicate architecture drafts, checkpoint inventory documents, and older workspace guidance.
- `reports/`: historical reports and MVP summaries.

## Archive Policy

Move files here when they are:

- phase-specific and already implemented
- old planning artifacts superseded by `ROADMAP.md`, `TASKS.md`, or `DECISIONS.md`
- duplicate architecture/security/roadmap drafts
- historical reports that should not guide current coding directly
