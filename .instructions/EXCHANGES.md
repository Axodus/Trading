# Trading Exchanges

# Purpose

Exchange systems coordinate:
- market access
- execution routing
- liquidity coordination
- telemetry
- portfolio exposure

Exchange integrations must remain modular.

---

# Exchange Categories

## Centralized Exchanges
CEX integrations.

Examples:
- Binance
- Bybit
- OKX
- Kraken

---

## Decentralized Exchanges
DEX integrations.

Examples:
- Uniswap
- PancakeSwap
- Curve
- Balancer

---

# Exchange Requirements

Exchange integrations must:
- expose telemetry
- expose execution state
- expose failure visibility
- expose routing visibility

---

# Exchange Constraints

Exchange systems must never:
- bypass risk systems
- bypass treasury controls
- bypass governance restrictions

---

# Routing Philosophy

Routing systems should prioritize:
- liquidity quality
- execution consistency
- treasury safety
- operational visibility

---

# Future Exchange Infrastructure

- cross-exchange routing
