# Trading Monetization

# Initial Boundary

Phase 0 defines internal billing and entitlement contracts without selecting a billing vendor.

---

# Supported Economic Shapes

- free access
- subscription access
- usage-aware access
- staking access
- DAO-funded access
- milestone-based unlocks

---

# Policies

Monetization policies must remain separate from:
- governance authorization
- disclosure acceptance
- risk approval
- runtime credential authorization

Entitlement success is necessary for some user flows, but never sufficient for execution.
